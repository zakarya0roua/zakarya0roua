# 🧑‍🏫 Nour Academy — Partie 3: Teacher Space

A browser-based teacher space for viewing student groups, tracking attendance, and managing grades.

## Features

- Display students belonging to a selected group
- Search and filter the student list
- Record student absences
- Add and validate grades
- Calculate student averages
- Highlight students who reach the three-absence alert threshold
- Update the interface dynamically after teacher actions

## Technologies and Concepts

- HTML and CSS
- Vanilla JavaScript
- DOM manipulation
- Event delegation
- `data-*` attributes and `closest()`
- Array methods such as `map()` and `find()`
- Browser-side data handling

## Project Context

The project focuses on helping teachers manage everyday classroom tasks through a simple interface, including attendance and student results.

## Run Locally

1. Clone this repository.
2. Open the project folder in your code editor.
3. Make sure the data file is loaded before the main JavaScript file, as required by the HTML page.
4. Start the page with a local development server if ES modules are used.
