# 🎓 Nour Academy — Course Registration Website

A browser-based registration website for tutoring and language courses. It helps parents browse available courses and submit a registration request through a validated form.

## Features

- Interactive course catalogue
- Filter courses by level and subject
- Display course availability and monthly prices
- Select courses and calculate the total amount
- Validate parent contact details and form fields
- Require explicit consent before submitting the form
- Show a registration summary in the browser

## Technologies

- HTML
- CSS / Tailwind CSS
- Vanilla JavaScript
- DOM manipulation
- Form validation
- Browser-side data handling

## Project Context

This project was built as a front-end registration experience for Nour Academy. It focuses on making course selection and registration clearer for parents on both desktop and mobile screens.

## Run Locally

1. Clone this repository.
2. Open the project folder in your code editor.
3. Follow the build or development instructions present in the repository, if provided.
4. Open the resulting local page in your browser.
