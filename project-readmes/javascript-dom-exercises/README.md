# 🧩 JavaScript DOM Exercises

A collection of exercises for practising JavaScript and working with the Document Object Model (DOM).

## Learning Goals

- Select HTML elements with JavaScript
- Read and update element content
- Create and insert elements dynamically
- Work with CSS classes
- Handle user events
- Practise common DOM interaction patterns

## Technologies

- HTML
- CSS
- JavaScript
- DOM API

## Run Locally

1. Clone this repository.
2. Open the project folder in your code editor.
3. Open the relevant exercise page in a browser, or use a local development server if required.
