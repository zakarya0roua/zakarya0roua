# 🍽️ Carnet de Recettes

An interactive recipe application that uses the DummyJSON API to let users browse and search recipes, and interact with recipe entries.

## Features

- Browse recipes retrieved from an API
- Search for recipes
- Add recipe entries through the application interface
- Remove recipe entries through the application interface
- Display recipe information dynamically

## Technologies and Concepts

- HTML and CSS
- JavaScript
- Fetch API
- REST API (DummyJSON)
- Promises / asynchronous JavaScript
- DOM manipulation

## What I Practised

This project helped me practise fetching external data, working with API responses, searching through data, and updating the DOM in response to user interactions.

## Run Locally

1. Clone this repository.
2. Open the project folder in your code editor.
3. Start the project with a local development server if required by the project structure.
4. Open the local address in your browser.
